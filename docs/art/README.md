# 그림 자료

2026-10-18에 이 게임을 위해 이미지 생성 도구로 새로 만든 그림입니다.

- `scenes-a.png`: 선물, 깨진 컵, 빈 캔, 책, 가방, 화분
- `scenes-b.png`: 공, 도서관 책, 카메라, 손수건, 공 바구니, 편지
- `clues.png`: `src/data.js`의 단서 순서와 같은 5열 × 4행 그림카드
- `people.png`: 준이·도윤·미소 / 나래·온유·다온의 3열 × 2행 인물 그림

원본은 그대로 보존하고 앱에서 SVG 뷰포트와 클립으로 필요한 부분을 표시합니다. 실제 패널 경계와 크기는 `src/art-manifest.json`에 기록합니다. 인물의 모자·안경·의상·신발은 단서 데이터와 함께 확인한 뒤 교체해야 합니다.
