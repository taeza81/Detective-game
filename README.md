# 꼬마 탐정단 · 그림카드 탐정 교실

그림과 음성 단서를 비교해 사람을 찾는 한국어 교육용 웹앱입니다. 유치원·초등학교에서 학생의 지원 필요에 맞춰 교사가 수업을 조절할 수 있습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 개발 환경은 Node.js 24로 검증했습니다.

```sh
cd /workspace/Detective-game
npm ci --cache /tmp/detective-npm-cache
npm run dev -- --port 5173
```

다른 위치에 복제했다면 해당 저장소 폴더에서 실행하세요. 클라우드 작업에서는 기존 체크아웃을 사용하며 별도의 Git worktree가 필요하지 않습니다.

## 포함된 기능

- 새로 생성한 그림책 화풍의 상황 그림 12개, 옷차림 단서 그림 20개와 인물 6명
- 인물 2~4명, 그림 단서 1~3개, 한 수업 3~5문제 설정
- 단서가 1개여도 표시된 선택지에서 정답이 유일하도록 선택지 구성
- 상황·단서 다시 듣기, 문제와 단서 자동 읽기 설정
- 정답은 짧은 칭찬 음성과 체크 표시, 재시도는 격려 음성과 돋보기 표시로 안내
- 정답·재시도 음성은 자동 읽기와 별도로 켜고 끄며, 화면 강조는 한 번만 재생하고 움직임 줄이기 설정을 반영
- 4단계 도움: 단서 확대 → 같은 신체·의상 부분 안내 → 나란히 확대 비교 → 단서에 맞지 않는 인물 흐리게 표시
- 인물을 누르면 답을 제출하거나, 별도의 확인 버튼으로 제출하도록 설정
- 독립 첫 선택 성공 / 도움 후 성공 / 도움 없이 재시도 후 성공을 구분한 학습 기록
- 첫 응답, 응답별 도움 단계, 최종 응답, 중간 마침 기록과 한국어 CSV 내려받기
- 새로고침 후 진행 중인 수업 이어하기
- 가로 태블릿·16:9 전자칠판에서 교실, 문제 풀이, 도움, 결과 화면을 스크롤 없이 사용
- 이야기 목록의 이전·다음 버튼으로 12개 상황 탐색
- 오른쪽 위 톱니바퀴로 교사 설정 열기, 수업 중 설정에서 원래 문제로 돌아오기
- 학생 화면의 질문·상황 설명은 한 번씩 표시하고, 단서는 짧은 이름과 큰 글씨로 제공
- 교사 설정의 큰 선택 버튼, 실시간 다음 수업 미리보기, 저장 여부 표시와 별도 설정 안내
- 오른쪽 위 전체화면 버튼, 전체화면에서 창모드 전환 버튼과 브라우저 종료 상태 동기화
- 모바일·태블릿 대응, 키보드 조작, 초점 표시, 대화상자 초점 관리, 움직임 줄이기 설정 반영

시간제한, 자동 정답 공개, 오답 경고음은 없습니다. 그림 단서 카드를 누르거나 음성을 다시 듣는 기본 활동은 추가 도움으로 집계하지 않습니다. **도움 버튼으로 제공한 최대 단계**를 별도로 기록합니다.

도움말은 상황 그림과 같은 공간에 표시되므로 인물 선택지가 화면 밖으로 밀려나지 않습니다. ‘상황 그림’ 버튼으로 원래 그림을 다시 볼 수 있으며, 사용한 도움 단계는 기록에 남습니다. 학생 활동은 화면 안에 맞춰지고, 교사의 긴 학습 기록 목록은 스크롤하여 열람할 수 있습니다. 전체화면은 브라우저 Fullscreen API를 사용하며, 이를 허용하지 않는 기기나 내장 브라우저에서는 지원 안내를 표시합니다.

## 음성과 저장

음성은 브라우저의 Web Speech API와 기기에 설치된 한국어 음성을 사용합니다. 한국어 음성의 사용 가능 여부와 품질은 기기·브라우저에 따라 다르며, 지원하지 않으면 안내 메시지와 그림·문장으로 참여할 수 있습니다. 외부 음성 API 키는 필요하지 않습니다.

학생 이름이나 개인정보를 입력하지 않습니다. 설정, 학습 기록, 진행 중인 수업은 현재 브라우저의 `localStorage`에 저장됩니다. 기기 간 동기화나 서버 저장은 제공하지 않습니다. 브라우저 데이터를 삭제하면 기록도 사라지므로 필요한 기록은 CSV로 보관하세요. 기록 삭제에는 확인 대화상자가 표시됩니다.

글꼴은 패키지에 포함되어 앱과 함께 제공됩니다. 실행 중 외부 글꼴 서버에 연결하지 않습니다.

## 검증과 빌드

### 웹 미리보기 없이 직접 열기

개발용 `index.html`은 Vite를 통해 실행해야 합니다. 이 파일만 단독으로 열거나 앱 파일 경로를 전달하지 못하는 미리보기에서 열면 JavaScript·CSS가 로드되지 않아 화면이 표시되지 않을 수 있습니다. 아래 명령으로 그림·글꼴·프로그램이 모두 포함된 HTML 실행본을 만들 수 있습니다.

```sh
npm run build:standalone
```

생성된 **`preview.html`** 또는 `standalone/꼬마탐정단.html` 파일을 컴퓨터로 내려받아 Chrome 또는 Edge에서 여세요. Node.js 설치나 서버 실행이 필요하지 않습니다. 파일의 위치나 이름을 바꾸면 브라우저에 저장된 기존 기록과 분리될 수 있습니다. 음성은 기기의 한국어 음성 지원을 사용합니다.

### 개발 및 기능 검증

```sh
npm test
npm run build
npm run preview -- --port 4173
```

`npm test`는 모든 상황에서 인물·단서 수 조합별 정답 유일성, 수업 구성, 도움 및 재시도 기록의 구분, 설정 복원을 확인합니다.

브라우저 기능 검증은 Python Playwright와 Chromium이 있는 환경에서 실행합니다. 개발 서버를 먼저 실행하세요.

```sh
python3 tests/browser_smoke.py
python3 tests/browser_classroom.py
python3 tests/browser_startup.py
# 배포 빌드 미리보기 서버를 검증하려면:
DETECTIVE_BASE_URL=http://127.0.0.1:4173 python3 tests/browser_smoke.py
```

Chromium 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다. 검사 결과 화면과 CSV는 Git에서 제외되는 `test-results/`에 생성됩니다. 음성 검사는 한국어 문장이 브라우저 음성 API로 전달되는지를 확인하며, 실제 소리 출력은 수업에 사용할 기기에서 확인해야 합니다.

`dist/`를 정적 웹 호스팅에 배포할 수 있습니다. 하위 경로에 배포하는 경우 Vite의 `--base` 옵션을 해당 경로로 설정해 빌드하세요.

## GitHub Pages: 브랜치로 배포하기

이 프로젝트는 **`main` 브랜치의 `/docs` 폴더**를 게시하도록 구성합니다. GitHub Pages는 Vite나 npm을 실행하지 않으므로 소스용 루트 `index.html`을 그대로 게시하면 앱의 JavaScript·CSS를 불러올 수 없습니다. `docs/`에는 빌드된 HTML·JavaScript·CSS·글꼴과 단일 파일 예비 실행본을 함께 저장합니다.

```sh
npm ci --cache /tmp/detective-npm-cache
npm test
npm run build:pages
```

생성된 `docs/`를 소스와 함께 `main` 브랜치에 커밋하고 GitHub에 반영한 뒤, 저장소에서 다음을 선택하세요.

1. **Settings → Pages**
2. **Source → Deploy from a branch**
3. **Branch → main**, 폴더 **/docs**
4. **Save**

처음 저장소에 커밋이 없으면 브랜치 목록에는 `None`만 표시됩니다. 첫 커밋을 GitHub에 올린 뒤 페이지를 새로고침하면 `main`을 선택할 수 있습니다.

배포가 완료되었을 때의 주소는 **https://taeza81.github.io/Detective-game/** 입니다. 실제 게시 완료는 Pages 화면의 상태 또는 해당 주소의 응답으로 확인해야 합니다. 이후 코드를 수정하면 `npm run build:pages`를 다시 실행하고 **소스와 `docs/`를 함께 커밋**하세요.

`vite.config.js`의 상대 경로 설정은 `/Detective-game/` 같은 저장소 하위 주소에서도 앱 파일이 올바르게 로드되도록 합니다. `.nojekyll`은 GitHub가 생성된 파일을 그대로 제공하도록 합니다. API 키·별도 서버·데이터베이스 설정은 필요하지 않습니다.

## 파일 구성

- `src/data.js`: 상황, 단서, 인물, 수업 구성 및 결과 분류
- `public/art/`: 새로 생성한 상황·단서·인물 그림 원본
- `src/art.js`, `src/art-manifest.json`: 그림 배치, 인물의 부분 확대와 테두리
- `src/main.js`: 화면, 수업 진행, 음성, 설정·기록 저장
- `src/style.css`: 그림카드형 디자인과 반응형 화면
- `src/classroom.css`: 화면 높이에 맞춘 터치 수업 레이아웃
- `src/ui-refinements.css`: 학생 화면의 글자 크기와 간결한 교사 설정 패널
- `src/feedback.css`: 정답·재시도 표시와 짧은 강조 효과
- `tests/game.test.js`: 핵심 학습 로직 검증
- `tests/browser_smoke.py`: 실제 브라우저 기능 검증
- `tests/browser_classroom.py`: 여러 16:9 해상도의 터치·스크롤·전체화면 검증

새로운 상황이나 의상을 추가할 때에는 인물의 `tags`, 설명, 그림이 일치하도록 수정하고 `npm test`를 실행하세요. 그림은 SVG 뷰포트와 클립으로 표시하므로 원본 이미지를 변형하지 않고도 개별 상황·단서를 보여 줍니다. 단일 HTML 실행본에는 이미지도 함께 포함됩니다.
